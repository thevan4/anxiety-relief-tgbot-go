# AnxietyHelp Bot

Telegram-бот для помощи при тревожности. Предоставляет научно обоснованные техники релаксации прямо в мессенджере.

## Возможности

### Быстрые техники (2-5 мин)
- **Дыхание за 2 минуты** — паттерн 4-4-6 для успокоения нервной системы
- **Якорение 5-4-3-2-1** — техника заземления через органы чувств

### Продвинутые техники (5-15 мин)
- **Управляемое дыхание** — 4 паттерна (коробочное, 4-7-8, энергичное, быстрый сброс)
- **Прогрессивная мышечная релаксация** — 10 групп мышц
- **Маркировка мыслей** — когнитивная техника работы с тревожными мыслями
- **Визуализация** — 5 расслабляющих сценариев

## Архитектура

```
cmd/
└── main.go                    # Точка входа

├── telegram/
```

## Запуск

Redis обязателен для работы бота (хранение состояния сессий). Используйте Docker Compose:

```bash
# Создать .env файл с токеном бота
echo "BOT_TOKEN=your_bot_token" > .env

# Запустить
docker-compose up -d --build
```

Остановка:

```bash
docker-compose down
```

## Redis и приватность

### Зачем Redis?

Redis используется **только** для хранения текущего состояния упражнения (state machine):

```
session:{user_id} → "breathing_running"  // TTL: 5 минут
```

Это позволяет:
- Отслеживать прогресс упражнения (на каком шаге пользователь)
- Корректно обрабатывать кнопки "Стоп", "Далее", "Завершить"
- Автоматически очищать незавершённые сессии через TTL

### Что НЕ хранится

| Не храним | Почему |
|-----------|--------|
| Личные данные | Приватность пользователей |
| История упражнений | Не требуется для работы бота |
| Тексты мыслей (маркировка) | Обрабатываются только в памяти, не сохраняются |
| Telegram ID долгосрочно | Ключи Redis имеют TTL 5 минут |
| Статистика | Хранится in-memory, теряется при перезапуске |

### Безопасность Redis

- Память ограничена 256MB (`maxmemory`)
- Политика eviction: `allkeys-lru` (удаляем старое при переполнении)
- TTL на ключах: 5 минут
- Нет persistence (данные в памяти)

## Разработка

### Структура кода

Тексты сообщений отделены от логики хендлеров:

```go
// internal/telegram/messages/breathing.go
const BreathingIntro = `🌬️ *Дыхание за 2 минуты* ...`

// internal/telegram/handlers/breathing_handler.go
h.bot.SendMessage(ctx, tu.Message(
    tu.ID(chatID),
    messages.BreathingIntro,  // Используем константу
).WithParseMode("Markdown"))
```

### Добавление новой техники

1. Создать данные в `internal/techniques/`
2. Создать сообщения в `internal/telegram/messages/`
3. Создать хендлер в `internal/telegram/handlers/`
4. Зарегистрировать в `bot_wrapper.go`
5. Добавить состояния в `internal/session/states.go`

### Тесты

```bash
go test ./...
```

## Ограничения

- Rate limit: 10 запросов/мин на пользователя
- Максимум 256MB памяти Redis
- Сессия истекает через 5 минут неактивности
