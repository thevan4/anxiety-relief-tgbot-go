# Anxiety Relief Bot

Telegram-бот с техниками для снятия тревожности. Go-порт [anxiety-aid-tools](https://github.com/msgnoki/anxiety-aid-tools).

## Техники

- **Дыхание 4-4-6** — 2 минуты
- **Заземление 5-4-3-2-1** — через органы чувств
- **Управляемое дыхание** — 4 паттерна (коробочное, 4-7-8, энергичное, быстрый сброс)
- **Прогрессивная мышечная релаксация** — 10 групп мышц
- **Маркировка мыслей** — когнитивная техника
- **Визуализация** — 5 сценариев

Поддержка: RU / EN

## Запуск

```bash
echo "BOT_TOKEN=your_token" > .env
docker-compose up --build
```

## Структура

```
internal/
├── session/      # State machine (Redis)
├── telegram/     # Bot handlers
├── techniques/   # Данные упражнений
└── localization/ # Переводы
```

## Приватность

- Хранится только текущее состояние упражнения (TTL 5 мин)
- Тексты мыслей не сохраняются
- История не ведётся
